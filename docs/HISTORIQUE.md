# Historique des décisions

1. **Point de départ** : une vidéo d'un outil de garage en vue isométrique (le garage modélisé,
   les voitures, les ateliers, les dossiers en cours). Question : un CRM gamifié de ce style pour
   Every1.ate ? Réponse : oui, à condition d'en faire une vue en plus des listes, pas un
   remplacement.
2. **Métaphore de cuisine écartée** : proposée à partir de nos phases (recette, cuisson, service),
   elle parlait de notre identité visuelle, pas de notre activité. Décision : la carte doit montrer
   l'activité réelle.
3. **Studio type écarté** : l'agence n'a pas de locaux ; chacun travaille de chez soi, depuis sa
   chambre. Décision : trois chambres-studios reliées par un QG virtuel.
4. **Validation (21 oct. 2026)** : s'inspirer de Habbo. L'outil doit améliorer la productivité, le
   suivi projet, le CRM, la capacité à finir ce qu'on fait, fluidifier la communication et la
   répartition des tâches. Il doit être « notre compagnon de travail ».
5. **Recherche** : trois agents indépendants (finir / CRM / équipe) ont proposé des mécaniques à
   partir du modèle de données réel (`docs/MECANIQUES.md`). Retenues dans la maquette :
   - dépasser la limite avec un motif ;
   - notes rattachées aux objets ;
   - stand-up pré-rempli ;
   - cartons sans responsable ;
   - passation de client avec acceptation ;
   - sonnette de relance ;
   - compte rendu à écrire ;
   - poussière et grand ménage.
6. **Maquette interactive** publiée (privée), puis transférée dans ce dépôt.
